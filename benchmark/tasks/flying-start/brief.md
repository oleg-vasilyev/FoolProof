# Бриф: награда FLYING START

Нужна новая награда на постере `/stats_awards`. Игрок вышел первым из каждой из
первых партий вечера — из первой, второй и третьей как минимум. Что было дальше,
неважно.

## Правило

- Срабатывает, когда один игрок выходил первым (Finish.First) в раунде 0, 1, 2 и так
  далее без разрыва, и такая серия от начала вечера длиной не меньше 3. Из партии
  первым выходит один человек, так что победитель всегда один.
- Игрок, который пришёл позже первой партии, награду не получает, даже если выиграл
  три подряд со своего прихода.
- Факт на строке постера — длина серии от начала вечера (3, 4, 5…).
- Вложенная пара: FLYING START **не печатается**, если HAT TRICK назвал того же
  игрока — четыре подряд уже сказали больше, чем три с начала. Пара идёт в
  `OVERSHADOWED` и в таблицу вложенных пар в `PLAN.md` с этой причиной.
- Отдельного порога по длине вечера у правила нет: короче пяти партий постер наград
  и так не рисуется.

## Замороженные имена (не менять)

- Каталог: `AwardName.FlyingStart = "flyingStart"`; член `Award`:
  `Earned<typeof AwardName.FlyingStart, { readonly run: number }>`.
- Правило: `export const flyingStart = (evening: SessionAppearances): Award | null` в
  `src/features/scoresheet/domain/awards/run-awards.ts`.
- Копи: `awardTitles.flyingStart` и `flyingStartReason(games: string)` в обеих
  таблицах. Английское название — `FLYING START`. Русское — на твой выбор, но не
  калька.
- Порядок печати (`RULES_IN_ORDER` и таблица каталога в `PLAN.md`): сразу после
  HAT TRICK.
- Частота **Fires** для `PLAN.md` и `RAREST_FIRST`: **4%** — считать не нужно, число
  дано (оценка 1/n² при 4–6 игроках); в `RAREST_FIRST` — сразу после FALSE DAWN,
  перед FIRST WIN.
- Случай галереи с именем `flying-start`, локаль `en`.

Вопросов задать некому: где бриф молчит, реши сам и назови решение в закрывающем
сообщении. Работа ведётся по правилам репозитория: все стадии, все гейты через
раннер, финальный коммит с числами гейтов по `write-a-commit`. Тег не резать, но
сообщение написать так, как для релиза.
